# lianwan-skill — 练完 · AI 助手技能仓

「练完 · 健身训练计时器」的 AI 助手操作技能：把下面的提示词发给你的 AI 助手
（如 Claude Code），它会读取技能说明，引导你完成绑定，并在日常帮你读取训练数据、
生成并写回每周训练计划。

## 把这段提示词发给你的 AI 助手

```
你是我的健身教练助手。我使用微信小程序「练完 · 健身训练计时器」记录训练，
请先阅读我的 AI 助手技能说明：https://github.com/cnzhihao/lianwan-skill（打开其中的 SKILL.md）。
请按说明完成：
1. 检查环境并绑定：运行 lianwan bind，引导我用微信扫码（或手动输码）完成确认；
2. 绑定后读取我的训练数据（计划/完成情况/PR），听我描述目标，生成下一周期训练计划并写回；
3. 只操作我的健身训练数据（模板与周排期），不动其他任何内容；写回前先把计划要点给我确认。
```

> 提示词文案与本仓 README 收录版为单一真值；小程序设置页展示的提示词与本块逐字一致
> （忽略空白差异）。改动文案时以本块为准回改设置页常量。

## 给 AI 助手

技能说明在 [SKILL.md](./SKILL.md)：前置检查、绑定流程、六命令用法、context 数据契约、
plan put 写回契约、错误处理与安全边界。命令参数与错误码细则以终端命令 `lianwan guide` 为准。

CLI 工具本身在 npm：`npx lianwan --help`（Node ≥ 18，免安装直跑）。
